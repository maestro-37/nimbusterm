NimbusTerm

A native SSH / SFTP terminal workspace for macOS — and a lighter, open-source alternative to MobaXterm.

macOS 14+ · Apple Silicon · SwiftUI · MIT license · free

Download for macOS View on GitHub ⭐ Star

Everything for daily SSH work

No Electron, no Java, no bundled X server. One native app on top of the system OpenSSH.

Terminal

Truecolor, 256 colors, mouse, links, scrollback, search, themes and a custom font.

Tabs & splits

Recursive splits, broadcast input to every pane, and layout restored on launch.

Sessions

Folders, tags, favorites, search, quick connect and duplicate. Local shell, SSH, SFTP, raw TCP.

SFTP

Remote browser with a built-in editor, transfer queue, chmod, rename and drag-and-drop.

Tunnels

Local, remote and dynamic SOCKS tunnels with status, stderr and autostart.

Keys

Browse ~/.ssh, generate ed25519 keys and install them with ssh-copy-id.

Monitoring

Load, RAM, disk and uptime over SSH in a compact status strip.

MobaXterm import

Bring existing .mxtsessions and ~/.ssh/config sessions with one click.

Install

Download the DMG, drag NimbusTerm into Applications, launch it.

Download the latest release — DMG, PKG or ZIP.

The app is ad-hoc signed. On first launch use right-click → Open, or remove the quarantine flag:

xattr -dr com.apple.quarantine /Applications/NimbusTerm.app

Build from source if you prefer:

git clone https://github.com/maestro-37/nimbusterm.git
cd nimbusterm
./scripts/build-app.sh
open dist/NimbusTerm.app

Security

An SSH client should not be a black box. The source is open and the design is boring on purpose.

Keychain only

Passwords and passphrases are stored in the macOS Keychain, never in the session library.

No secrets in argv

Credentials reach ssh and sftp through an askpass helper, not the process list.

System OpenSSH

Agent, keys, config, ProxyJump, FIDO and host-key checks come from Apple's OpenSSH.

Open source

MIT licensed. Read the code, build it yourself, report issues privately via the security policy.
